    BatchResponse

    Type, Introduced in version 2.18

    The response object used by the batching system to return the complete result of an entire batch of commands.

    Properties

    Name Type Summary Introduced in
    IsSuccessful Boolean Specifies if the batch was successfully committed or not.
    Response EntityCommandResponse[] The individual commmand responses in the batch.

    When the batch command includes commands that uses the /Many tag the responses are flattened out.
    You still get one result per individual command, but to be able to match the responses, the batch command also needs to be flattened out.
    FailingIndex Int32? The index of the failing command in the batch.
    ErrorMessage String The error message of the failure that caused the batch to
    be rolled back.

    Example

    {
  "IsSuccessful": false,
  "Response": null,
  "FailingIndex": null,
  "ErrorMessage": null
}
