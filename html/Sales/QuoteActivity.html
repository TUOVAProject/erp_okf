    QuoteActivities

    Queryable, Introduced in version 24.2

    GET https://localhost:8001/sv/001.1/api/v1/Sales/QuoteActivities

    Represents a quote activity.

    GUID

    95D6B3A6-2EC0-4C17-B998-B32A14DB52E8

    Required permission

    Show quote

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the quote activity.
    QuoteId Int64 The business key identifier of the quote this activity belongs to.

    • References Quotes
    IsMandatory Boolean Specifies if this activity is mandatory.
    ActivityTypeId Int64 The business key identifier of the activity's type.

    • References CustomerRelationshipActivityTypes
    CalendarAppointmentId String The calendar appointment id of the activity.

    • Max length is 256
    CompletedByUserId Int64? The business key identifier of the user who completed this activity.

    • References ApplicationUsers
    ResponsibleUserId Int64? The business key identifier of the user who is responsible for this activity.

    • References ApplicationUsers
    Description String The translated description of the activity.

    • Max length is 400
    CommentId Int64? The business key identifier of the activity's comment.

    • References Comments
    Comment Comments The comment of the activity.

    • Expandable
    Status Int32 The status of the activity.

    • Registered: 1
    • InProgress: 2
    • History: 9
    ReminderId Int64? The business key identifier of the activity's reminder.

    • References Reminder
    PlannedCompletionDate DateTimeOffset The planned completion date of the activity.
    CompletionDate DateTimeOffset? The completion date of the activity.
    PlannedStartDate DateTimeOffset? The planned start date of the activity.
    ActualStartDate DateTimeOffset? The actual start date of the activity.
    IsAdministratorResponsibleUser Boolean Specifies if the administrator is the responsible user of the activity.
    NumberDaysFromDueDate Int32? Specifies number of days from due date on this activity.
    IsDueDatePlannedCompletionDate Boolean Specifies if due date id planned completion date on the activity.
    DueDateType Int32 The due date type of the activity.

    • RegistrationDate: 0
    • ValidThrough: 1
