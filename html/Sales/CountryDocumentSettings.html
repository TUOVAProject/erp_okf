    CountryDocumentSettings

    Queryable, Introduced in version 26.3

    GET https://localhost:8001/sv/001.1/api/v1/Sales/CountryDocumentSettings

    Represents a country document setting.

    Note the values in this entity can be overridden on each customer by CustomerCountryDocumentSettings.

    GUID

    4a2c8077-1f23-4cd8-8c5a-4f70af4348fa

    Required permission

    Modify settings for file viewer

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the country document setting.
    RowIndex Int32? The row index of the document setting.
    CountryId Int64 The business key identifier of the document setting's country.

    • References Countries
    ShowInSalesForm Int32 Specifies the document type this setting applies to.

    • None: 0
    • Quote: 1
    • Acknowledgement: 2
    • DeliveryNote: 4
    • Invoice: 8
    • ProFormaInvoice: 16

    • Bitmask
    ShowCountryOfOrigin Boolean Specifies if this setting should show country of origin.
    ShowNetWeight Boolean Specifies if this setting should show net weight.
    ShowTradeClassificationName Boolean Specifies if this setting should show trade classification name.
    ShowCN Boolean Specifies if this setting should show CN.
    ShowHS Boolean Specifies if this setting should show HS.
    ShowTaric Boolean Specifies if this setting should show taric.
    ShowHTS Boolean Specifies if this setting should show HTS.
    ShowNCM Boolean Specifies if this setting should show NCM.
    ShowECCN Boolean Specifies if this setting should show ECCN.
    ShowSITC Boolean Specifies if this setting should show SITC.
    AmountExcludedDiscount Boolean Specifies if this setting should show amount excluded discount.
    TotalByCombCode Int32 Specifies which classification code system drives the "Total by Comb. n. code" summary section on Pro forma and Comprehensive proforma invoices. Only meaningful when is .

    • HS: 1
    • Taric: 2
    • HTS: 3
    • NCM: 4
    • ECCN: 5
    • SITC: 6
