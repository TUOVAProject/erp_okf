    Locations

    Queryable, Introduced in version 24.4

    GET https://localhost:8001/sv/001.1/api/v1/Inventory/Locations

    Represents a location (so called generated location) Can also represent a stock package)

    GUID

    11397529-3969-44E4-8142-B0CBAA05FD06

    Required permission

    Show locations

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the location.
    ParentId Int64? The business key identifier of the location's parent location.
    Applicable for locations that represents a stock package.

    References Locations
    WarehouseId Int64 The business key identifier of the warehouse where the location is located.

    • References Warehouses
    Warehouse Warehouses The warehouse of the location.

    • Expandable
    Name String The name of the location or the package number.

    • Not nullable
    • Max length is 35
    StorageType Int32 The type of the location. (Single- or multipart storage)

    • SinglePartStorage: 0
    • MultiplePartStorage: 1
    CommentId Int64? The business key identifier of the comment

    • References Comments
    Comment Comments The comment of the location.

    • Expandable
    BlockedById Int64? The business key identifier of the application user that blocked the entity.

    BlockedBy ApplicationUsers The application user that blocked the location.

    • Expandable
    BlockedStatus Int32 The block status of the entity.

    • None: 0

    • Blocked: 2
    BlockMessageId Int64? The business key identifier of the entity block message comment.
