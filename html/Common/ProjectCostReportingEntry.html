    ProjectCostReportingEntries

    Queryable, Introduced in version 2.50

    GET https://localhost:8001/sv/001.1/api/v1/Common/ProjectCostReportingEntries

    Represents a project cost reporting entry.

    GUID

    d7e1f4c3-f042-479b-b9f5-b091619eae87

    Required permission

    Report activity for any user

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the project cost reporting entry.
    Number Int64 The human readable identifier of the project cost reporting entry.
    ProjectId Int64? The business key identifier of the project linked to the project cost reporting entry.

    • References Project
    IsIncome Boolean Specifies if the project cost reporting entry concerns income.
    ActivityId Int64? The business key identifier of the project activity linked to the project cost reporting entry.

    • References ProjectActivity
    ReportedTimeInHours Decimal The time in hours reported by the project cost reporting entry.
    CostTypeId Int64? The business key identifier of the cost type linked to the project cost reporting entry.

    • References ProjectCostType
    Amount Decimal The amount reported by the project cost reporting entry.
    ReportingDate DateTimeOffset The date of the project cost reporting entry.
    OurReferenceId Int64? The business key identifier of the reference for the project cost reporting entry.

    • References Person
    OurReferenceName String The name of our reference for the project cost reporting entry.
    EmployeeId Int64? The business key identifier of the employee that performed the reporting.

    • References Person
    WorkCenterId Int64? The business key identifier of the work center the reporting concerns.

    • References WorkCenter
    DepartmentId Int64? The business key identifier of the department the reporting concerns.

    • References Department
    IsCancelled Boolean Specifies if the project cost reporting entry is cancelled.
    CommentId Int64? The business key identifier of the comment for the project cost reporting entry.

    • References Comment
    Comment Comments The comment of the project cost reporting entry.

    • Expandable
    CustomerReference String Customer reference for the project cost reporting entry. Entered per log in Authorize/adjust and copied from the work recording.

    • Max length is 80
    		 Introduced in version 26.6
    CustomerOrderNumber String Customer order number for the project cost reporting entry. Entered per log in Authorize/adjust and copied from the work recording.

    • Max length is 15
    		 Introduced in version 26.6
    GoodsMark String Goods mark for the project cost reporting entry. Entered per log in Authorize/adjust and copied from the work recording.

    • Max length is 80
    		 Introduced in version 26.6
    InternalCommentId Int64? The business key identifier of the internal comment for the project cost reporting entry.

    • References Comment
    		 Introduced in version 26.6
    InternalComment Comments The internal comment of the project cost reporting entry.

    • Expandable
    		 Introduced in version 26.6
