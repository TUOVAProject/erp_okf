    EntityChangeLogs

    Queryable, Introduced in version 2.33

    GET https://localhost:8001/sv/001.1/api/v1/Common/EntityChangeLogs

    Represents a queryable entity changelog entry.

    GUID

    408514C1-E8D8-47BB-9368-AE82AB2D9FB0

    Required permission

    Show changelog

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the changelog entry.
    ChangeType Int32 The type of change that was made to the entity.

    • Update: 0
    • Create: 1
    • Delete: 2
    EntityTypeId Guid The GUID of the changed entity's type.
    EntityId Int64 The business key identifier of the changed entity.
    ModifiedBy String The human readable identifier of the application user that performed the change.

    • Max length is 20
    • Not nullable
    ModifiedTimestamp DateTimeOffset The date when the change was made.
    AssociatedTypeId Guid? The GUID of the changed entity's parent type.
    AssociatedEntityId Int64? The business key identifier of the changed entity's parent.
    EntityCode String The human readable identifier of the changed entity.

    • Max length is 255
    Changes EntityPropertyChanges[] The property changes for this entity.
    Remark String Holds extra information about the change.

    • Max length is 100

}
