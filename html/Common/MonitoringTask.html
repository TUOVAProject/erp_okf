    MonitoringTasks

    Queryable, Introduced in version 24.7

    GET https://localhost:8001/sv/001.1/api/v1/Common/MonitoringTasks

    Represents a monitoring task.

    GUID

    12a7006c-bc65-4e18-9029-4fe3d9854be0

    Required permission

    Create and handle all monitoring tasks

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the monitoring task.
    Number String The monitoring task number.

    • Unique
    • Max length is 20
    Name String The name of monitoring task.
    TaskType Int32 The type of monitoring task.

    • StockBalance: 0
    • PersonActivity: 1
    • CustomerActivity: 2
    • QuoteActivity: 3
    • CustomerOrderActivity: 4
    • SupplierActivity: 5
    • PartActivity: 6
    • PurchaseOrderActivity: 7
    • InquiryActivity: 8
    • ManufacturingOrderOperation: 9
    • ArrivalReporting: 10
    • OrderRowArrivalReporting: 11
    • BlanketOrderPurchaseActivity: 12
    • BlanketOrderSalesActivity: 13
    • SalesAgreementActivity: 14
    • CaseEntryActivity: 15
    • ExposureTime: 16
    • BusinessOpportunityActivity: 17
    • ProductRecordActivity: 18
    • SupplierAgreementActivity: 19
    Status Int32 The status of monitoring task.

    • Active: 0
    • Disabled: 1
    UseSchedule Boolean Specifies if the monitoring task should be used in schedule.
    RunOnce Boolean Specifies if the monitoring task should be deactivated when any of the terms are fulfilled.
    StartTime DateTimeOffset? The start time of the monitoring task.
    StopTime DateTimeOffset? The end time of the monitoring task.
    ApplicationUserId Int64 The business key identifier of the application user that create the monitoring task.

    • References ApplicationUsers
    ApplicationUser ApplicationUsers The application user that create the monitoring task.

    • Expandable
    CommentId Int64 The business key identifier of the monitoring task's comment.

    • References Comments
    Comment Comments The monitoring task's comment.

    • Expandable
