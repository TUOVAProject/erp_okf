    StandbyWorks

    Queryable, Introduced in version 2.26

    GET https://localhost:8001/sv/001.1/api/v1/TimeRecording/StandbyWorks

    Represents a work put on standby.

    GUID

    2D0EFE39-5F0A-4FD5-86C4-2E497793ED96

    Required permission

    Show recording items

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the standby work.
    EmployeeId Int64 The business key identifier of the employee who has this work on standby.

    References Persons
    BundleId Guid The bundle id of the work. Used to identify if work should be started as a bundle when restarting.
    WorkRecordingType Int32 What type of work this represents.

    • Indirect: 0
    • OperationSetup: 1
    • OperationUnit: 2
    • ProjectActivity: 3
    IndirectWorkCodeId Int64? The business key identifier of the indirect work code, defined when WorkRecordingType is Indirect.

    References
    IndirectWorkCode IndirectWorkCodes The indirect work code, available when WorkRecordingType is Indirect.

    • Expandable
    OperationId Int64? The business key identifier of the operation, defined when WorkRecordingType is OperationSetup or OperationUnit.

    References ManufacturingOrderOperations
    Operation ManufacturingOrderOperations The operation for this work, available when WorkRecordingType is OperationSetup or OperationUnit.

    • Expandable
    ActivityId Int64? The business key identifier of the activity, defined when WorkRecordingType is Activity.

    References a project activity.
