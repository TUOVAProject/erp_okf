    AttendanceChart

    Queryable, Introduced in version 2.18

    GET https://localhost:8001/sv/001.1/api/v1/TimeRecording/AttendanceChart

    Represents an attendance chart.

    Required permission

    Show recording items

    Properties

    Name Type Summary Introduced in
    Id Int64 The business key identifier of the latest recording day.

    References RecordingDays
    RecordingDate DateTime The date of the last recording.
    EmployeeId Int64 The business key identifier of the employee that the recording
    belongs to.

    References Persons
    EmployeeNumber String The employee number of the recording employee.

    • Max length is 10
    FirstName String The first name of the recording employee.

    • Max length is 35
    LastName String The last name of the recording employee.

    • Max length is 35
    InternalPhoneNumber String The internal phone number of the recording employee.

    • Max length is 80
    IsClosedInterval Boolean Specifies if the interval of the attendance period has been closed.
    IntervalStart DateTimeOffset When the interval started.
    IntervalEnd DateTimeOffset When the interval ended.
    AbsenceCodeId Int64? The business key identifier of the recording's absence code.
    AbsenceCode String The human readable identifier of the recording's absence code.

    • Max length is 4
    AbsenceDescription String The absence code description.

    • Max length is 35
    IsBreak Boolean Specifies if the interval is considered break time.
    ScheduleId Int64? The business key identifier of the schedule that the recording
    is based upon.
    AbsenceKind Int32 The absence kind of the recording.
    ScheduleType Int32? The schedule type of the recording.

    Represents Monitor.StrawberryFields.Shared.Workshop.WorkshopScheduleType
    1 - Ordinary
    2 - Overtime
    IsNightSchedule Boolean? Specifies if the recording falls under night schedule.
    ScheduleNumber String The schedule number of the recording.

    • Max length is 10
    DepartmentId Int64 The business key identifier of the department linked to the recording.
    DepartmentCode String The department code of the recording.

    • Max length is 6
