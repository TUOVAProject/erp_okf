CreateSalesPickingList

Operation Create on the Monitor API.

Creates picking lists.

Module
Sales
API class
CreateSalesPickingList
Endpoint
POST /api/v1/Sales/SalesPickingLists/Create
Required permission
Show customer orders
Introduced in
2.53

Notes

  • Returns Int64 [] (the collection of picking list ids created).

Request body

Property Type Null References Constraints Description
DeliveryRows DeliveryRow[] collection Collection of the customer order rows that should be added to the picking list.
CreatedByPersonId Int64? null Persons The business key identifier of the person that created the picking list.
OutgoingDeliveryLocationName String max length 35 The name of the outgoing delivery location for the picking list.
