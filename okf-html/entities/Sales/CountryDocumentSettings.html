CountryDocumentSettings

Represents a country document setting.

API class

Notes

  • Note the values in this entity can be overridden on each customer by CustomerCountryDocumentSettings .

Properties

Property Type Null References Constraints Description

CountryId Int64 Countries The business key identifier of the document setting's country.
ShowInSalesForm Int32 bitmask, enum Specifies the document type this setting applies to.
ShowCountryOfOrigin Boolean Specifies if this setting should show country of origin.
ShowNetWeight Boolean Specifies if this setting should show net weight.
ShowTradeClassificationName Boolean Specifies if this setting should show trade classification name.

ShowSITC Boolean Specifies if this setting should show SITC.
