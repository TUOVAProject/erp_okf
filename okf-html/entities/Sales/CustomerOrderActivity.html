Property Type Null References Constraints Description
Id Int64 The business key identifier of the customer order activity.
OrderId Int64 CustomerOrders The business key identifier of the customer order to add the activity to.
ActivityTypeId Int64 CustomerRelationshipActivityTypes The business key identifier of the customer order activity type that the activity is based on.
Description String default: From the activity type The description of the activity.
ResponsibleUserId Int64 ApplicationUsers The business key identifier of the application user that is responsible for the activity.
PlannedCompletionDate DateTimeOffset The planned completion date of the activity.
