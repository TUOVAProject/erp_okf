BatchResponse

The response object used by the batching system to return the complete result of an entire batch of commands.

Module
Infrastructure
API class
BatchResponse
Endpoint
none — this is a payload type, not a queryable resource.
Introduced in
2.18

Properties

Property Type Null References Constraints Description
IsSuccessful Boolean Specifies if the batch was successfully committed or not.
Response EntityCommandResponse[] EntityCommandResponse collection The individual commmand responses in the batch. When the batch command includes commands that uses the /Many tag the responses are flattened out. You still get one result per individual command, but to be able to match the responses, the batch command also needs to be flattened out.
FailingIndex Int32? null The index of the failing command in the batch.
ErrorMessage String The error message of the failure that caused the batch to be rolled back.

Example

{
  "IsSuccessful": false,
  "Response": null,
  "FailingIndex": null,
  "ErrorMessage": null
}
