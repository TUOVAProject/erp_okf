Properties

Property Type Null References Constraints Description
Id Int64 The business key identifier of the payment term.
Number Int64 The payment term number.
Description String The translated description of the payment term.
GracePeriodInDays Int32 The grace period of the payment term specified in days.
IsFreeDeliveryMonth Boolean deprecated since 22.4 Specifies if the payment term implies a free delivery month. (Replaced by Method)
Method Int32 enum, since 22.4 The method of the payment term.
AddDaysToEOM Int32 since 22.4 The number of days to add to the due date when using the end of month method.
IsDefault Boolean Specifies if the payment term is the default.
InvoiceType Int32 enum The invoice type of the payment term.
PaymentMethodId Int64? null PaymentMethods The business key identifier of the payment method of the payment term. References PaymentMethods .
CompanyIds Int64[] collection The business key identifiers of the companies that this entity is available for.
Code String max length 15, since 24.8 The code of the payment term.
