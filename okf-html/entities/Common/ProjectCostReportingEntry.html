ProjectCostReportingEntries

Represents a project cost reporting entry.

Module
Common
API class
ProjectCostReportingEntry
Endpoint
GET /api/v1/Common/ProjectCostReportingEntries
Required permission
Report activity for any user
GUID
d7e1f4c3-f042-479b-b9f5-b091619eae87
Introduced in
2.50

Properties

Property Type Null References Constraints Description
Id Int64 The business key identifier of the project cost reporting entry.
Number Int64 The human readable identifier of the project cost reporting entry.
ProjectId Int64? null The business key identifier of the project linked to the project cost reporting entry.
IsIncome Boolean Specifies if the project cost reporting entry concerns income.
ActivityId Int64? null The business key identifier of the project activity linked to the project cost reporting entry.
ReportedTimeInHours Decimal The time in hours reported by the project cost reporting entry.
CostTypeId Int64? null The business key identifier of the cost type linked to the project cost reporting entry.
Amount Decimal The amount reported by the project cost reporting entry.
ReportingDate DateTimeOffset The date of the project cost reporting entry.
OurReferenceId Int64? null The business key identifier of the reference for the project cost reporting entry.
OurReferenceName String The name of our reference for the project cost reporting entry.
EmployeeId Int64? null The business key identifier of the employee that performed the reporting.
WorkCenterId Int64? null The business key identifier of the work center the reporting concerns.
DepartmentId Int64? null The business key identifier of the department the reporting concerns.
IsCancelled Boolean Specifies if the project cost reporting entry is cancelled.
CommentId Int64? null The business key identifier of the comment for the project cost reporting entry.
Comment Comments Comments expandable The comment of the project cost reporting entry.
CustomerReference String max length 80, since 26.6 Customer reference for the project cost reporting entry. Entered per log in Authorize/adjust and copied from the work recording.
CustomerOrderNumber String max length 15, since 26.6 Customer order number for the project cost reporting entry. Entered per log in Authorize/adjust and copied from the work recording.
GoodsMark String max length 80, since 26.6 Goods mark for the project cost reporting entry. Entered per log in Authorize/adjust and copied from the work recording.
InternalCommentId Int64? null since 26.6 The business key identifier of the internal comment for the project cost reporting entry.
InternalComment Comments Comments expandable, since 26.6 The internal comment of the project cost reporting entry.
