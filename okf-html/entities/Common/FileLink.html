FileLink

Represents a file that has been linked to a comment.

Module
Common
API class
FileLink
Endpoint
none — this is a payload type, not a queryable resource.
Introduced in
2.18

Notes

  • Used by the Comments entity.

Properties

Property Type Null References Constraints Description
Id Int64 The business key identifier of the file link.
FilePathId Int64 since 2.44 The business key identifier of the file path.
FileLinkContainerId Int64 since 2.44 The business key identifier of the file link container.
IsDefault Boolean Specifies if the linked file should be selected by default.
IsGenerated Boolean Specifies if the linked file has been automatically generated by MONITOR or not.
Filename String max length 255 Specifies the filename of the linked file.
Directory String max length 255 Specifies the directory path of the linked file.
Orientation Int32 enum, since 2.44 Specifies the preferred printing orientation of the file.
AutomaticPrintOut Boolean since 2.44 Specifies if the linked file should use automatic printouts.
GenerateCopies Boolean since 2.44 Specifies if the linked file should generate copies.
AllowExternalEditing Boolean deprecated since 23.6, since 2.44 Specifies if the linked file allows external editing. (Will always return true.)
PrinterType Int32 enum, since 2.44 Specifies the preferred printer type of the file.
SharePointFileVersion String since 25.8 Specifies the SharePoint file version if file type is SharePoint.
UseLatestPublishedVersion Boolean since 25.8 Specifies if need to use latest published SharePoint file when file type is SharePoint.
