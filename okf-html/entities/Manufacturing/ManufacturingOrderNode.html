ManufacturingOrderNodes

Represents a manufacturing order node.

Properties

Property Type Null References Constraints Description
Id Int64 The business key identifier of the manufacturing order node.
IsMainNode Boolean Specifies if the node is the main node on manufacturing order. Only one of the root nodes on order can be the main node.
IsRootNode Boolean Specifies if the node is a root node on manufacturing order. It can be several root nodes. For example when splitting from max quantity or when coordinated parts exists. Only one of the root nodes on order can be the main node.
Level Int32 Level in the node hierarchy
Number Int32 Node number, a sequence number in exploding sort order.
PartId Int64 Parts The business key identifier of the part that the manufacturing order node is to produce.
ReportedQuantity Decimal The reported quantity.
PlannedQuantity Decimal The planned quantity.
RestQuantity Decimal The rest quantity.
StartDate DateTimeOffset The start date of the manufacturing order node.
EndDate DateTimeOffset The finish date of the manufacturing order node.
WarehouseId Int64 Warehouses The business key identifier of the warehouse that the node belongs to.
Status Int32 enum The status of the manufacturing order node.
ManufacturingOrderNodeId Int64? null ManufacturingOrderNodes The business key identifier of the manufacturing order node that the manufacturing order node belongs to. If id is null, it's a root node.
Drawings ManufacturingOrderNodeDrawings[] ManufacturingOrderNodeDrawings expandable, collection, since 24.2 A collection of drawings that belong to the manufacturing order node.
RevisionId Int64? null Revisions since 24.2 The business key identifier of the revision that the manufacturing order node has.
Revision Revisions Revisions expandable, since 24.2 The revision that the manufacturing order node has.
SerialNumberProductRecords ProductRecords[] ProductRecords expandable, collection, since 25.2 A collection of product records with serial number traceability that belong to the manufacturing order node.
