Properties

Property Type Null References Constraints Description
Id Int64 The business key identifier of the standby work.
EmployeeId Int64 Persons The business key identifier of the employee who has this work on standby.
BundleId Guid The bundle id of the work. Used to identify if work should be started as a bundle when restarting.
WorkRecordingType Int32 enum What type of work this represents.
IndirectWorkCodeId Int64? null IndirectWorkCodes The business key identifier of the indirect work code, defined when WorkRecordingType is Indirect.
IndirectWorkCode IndirectWorkCodes IndirectWorkCodes expandable The indirect work code, available when WorkRecordingType is Indirect.
OperationId Int64? null ManufacturingOrderOperations The business key identifier of the operation, defined when WorkRecordingType is OperationSetup or OperationUnit.
Operation ManufacturingOrderOperations ManufacturingOrderOperations expandable The operation for this work, available when WorkRecordingType is OperationSetup or OperationUnit.
ActivityId Int64? null The business key identifier of the activity, defined when WorkRecordingType is Activity. References a project activity.
