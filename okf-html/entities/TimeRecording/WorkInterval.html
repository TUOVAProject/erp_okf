Properties

Property Type Null References Constraints Description
Id Int64 The business key identifier of a work interval.
IntervalStart DateTimeOffset The start of the interval.
IntervalEnd DateTimeOffset The end of the interval.
IsClosedInterval Boolean Indicatates if the interval was ended. If false the interval is considered an active interval on the day which a future work recording is supposed to end.
BundleId Guid Identifier to detect what work was recorded in the same bundle.
WorkRecordingType Int32 enum What type of work this recording represents. Indicates which id is relevant on the interval.
IndirectWorkCodeId Int64? null IndirectWorkCodes The business key identifier to an indirect work code. Defined if is indirect work.
OperationId Int64? null ManufacturingOrderOperations The business key identifier to a manufacturing order operation. Defined if it is an operation unit or a setup recording.
TimeCalculationType Int32 enum The time calculation type for this interval.
ReportingEmployeeId Int64 Persons The business key identifier to the employee making the recording. When machine recording this key will represent the operator if defined. Otherwise this will be the same as the person owning the recording day.
WorkCenterId Int64? null WorkCenters The business key identifier to the workcenter associated with the recording.
WorkedTime TimeSpan The calculated work time for this interval.
OfWichOvertime TimeSpan How much of the worked time that was considered overtime.
ReportedQuantity Decimal The reported quantity for this recording.
RejectedQuantity Decimal The rejected quantity for this recording.
ActivityId Int64? null ProjectActivities since 22.6 The business key identifier to a project activity. Defined if it is a project activity.
CommentId Int64? null Comments since 23.8 The business key identifier of the work interval comment.
Comment Comments Comments expandable, since 23.8 The comment of the work interval.
